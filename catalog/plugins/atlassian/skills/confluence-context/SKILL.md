# Read the docs in Confluence

1. Search Confluence for the service, module or feature name, plus "runbook", "architecture" or "decision" as needed.
2. Read the most recently updated relevant pages, and note each page's last edit date.
3. Summarize what they say that matters for the current task.
4. Compare it with the code. List each place where the docs are out of date, and offer to draft an update for the page.
