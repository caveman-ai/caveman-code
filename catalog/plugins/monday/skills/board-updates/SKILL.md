# Update a monday.com board

1. Find the board and the item: by name or ID if given, else search the board for the feature or bug.
2. Read the item's columns and recent updates so the new update does not repeat them.
3. Post an update: what changed, the link to the commit or PR, and what is left.
4. Change status, owner or dates only when the user asks.
