# Plan work in Asana

1. Confirm the workspace and project (and section, if the project uses them).
2. Split the plan into tasks that are each one reviewable change. Each title says the outcome; each description lists the files involved and how it will be checked.
3. Show the list, then create the tasks in order. Set assignees and due dates only when the user gave them.
4. As work lands, comment on the matching task with the commit or PR link, and complete it only when the user agrees it is done.
