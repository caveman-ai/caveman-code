# Catch up on Slack

1. Work out the scope: the channels the user names, else the channels tied to this repository or team. Ask if unsure; do not read every channel.
2. Read messages since the time the user gives (default: the last working day), including thread replies.
3. Summarize in three short sections:
   - Decisions made.
   - Questions or requests addressed to the user, with a link to each message.
   - Anything that touches the code in this repository (incidents, broken builds, review requests).
4. Quote people only where wording matters. Do not repeat private or sensitive content beyond what the summary needs.
