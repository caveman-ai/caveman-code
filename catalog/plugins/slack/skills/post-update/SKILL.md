# Post an update to Slack

1. Gather the facts from the repository: what changed (commits, PR title and link), why, and any action others must take.
2. Draft the message: one line saying what happened, then up to three bullets, then links. No filler.
3. Show the draft and the target channel or thread. Wait for approval of the exact text.
4. Post it, in the thread if one exists. Reply with the message link.

Never post to a channel the user did not name, and never mention @channel or @here unless asked.
