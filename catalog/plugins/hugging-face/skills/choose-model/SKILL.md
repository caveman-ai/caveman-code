# Choose a model from the Hub

1. Pin down the task, the languages, the hardware it must run on, and whether commercial use is needed.
2. Search the Hub for that task and sort by downloads and recent updates.
3. For the top candidates, read the model card: licence, parameter count, context length, the evaluation results the card reports, and known limits.
4. Drop models whose licence or size does not fit. Compare the rest in a short table.
5. Recommend one and show the few lines of code to load it with the library this repository already uses.
