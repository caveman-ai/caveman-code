# Publish notes to Notion

1. Collect facts from the repository: commits, diff and PR description. Do not invent motivation; ask if the why is missing.
2. Choose the shape:
   - Design notes: problem, decision, alternatives considered, consequences.
   - Release notes: what changed for users, in their words, then anything they must do.
3. Find where it belongs (a parent page or database the user names, or search for the team's docs space). Match the format of sibling pages.
4. Show the draft, then create the page. Reply with its link.
